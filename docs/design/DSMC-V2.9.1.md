# DSMC v2.9.1 变更说明

> 起因：v2.9.0 的 neo 主题上线后，用户截图反馈两件事 ——
> 一是微信图标的左边缺了一块；二是整页只有紫、黄两个点缀色，
> 希望"多用一些颜色，显得活泼多彩灵动"。

## 一、微信图标：路径没闭合

旧版想画"两个叠在一起的气泡"：

```js
wechat: '<path d="M9.6 3.5C5.5 3.5 2.2 6.3 2.2 9.8c0 2 1.1 3.8 2.9 5l-.8 2.5 2.9-1.4c.7.2 1.5.3 2.3.3"/>'
```

路径从左上起笔，绕到左下、画出小尾巴、再往右上收 —— 然后就**停了**，
没有 `z` 也没有回到起点。少的那一段正好是"接回起笔点"的那根弧线，
14px 下就是一个 C 形缺口。深色主题里底色相近不明显，neo 的奶油底上直接暴露。

改成一个**闭合的圆气泡 + 两只眼睛**（官方图标就是这个形状）：

```
M20.2 11.2c0-4.1-3.7-7.4-8.2-7.4S3.8 7.1 3.8 11.2
c0 2.3 1.2 4.4 3.1 5.7l-.9 3.1 3.4-1.7
c.8.2 1.7.3 2.6.3 4.5 0 8.2-3.3 8.2-7.4z
```

一个 `M`、一个 `z`，尾巴由路径自身围出来，不会再有缺口。
眼睛用 `fill="currentColor" stroke="none"` 的两个圆点 ——
`icon()` 在外层统一给了 `fill="none"`，子元素必须自己覆盖回来。

**顺手加的断言**（`test/ui-market.test.js`）：路径必须以 `z` 结尾、
只有一个 `M`、正好两个 `<circle>`。以后谁再手改这个图标，闭合问题会被立刻抓住。

## 二、加颜色：黑描边当骨架，颜色当贴纸

v2.9.0 的 neo 只有紫（LOGO）和黄（荧光笔）两处颜色，剩下全是奶油 + 黑。
参考站（`ip.fs.kg`）之所以活泼，是因为**颜色面积小但数量多**：
紫色面板、柠檬绿按钮、各种彩色小标签，全被黑描边框住。

所以这轮的原则是：

- **骨架不动** —— 描边、硬投影、圆角全部保持黑色，版面不散
- **卡片底色不动** —— 卡片仍是奶油色。反过来给每张卡上色，一屏十几张就是调色盘
- **颜色只贴在小块上** —— 徽标、分类、胶囊、按钮、整块面板

### 色板

```css
--lime:#C8F169  --sky:#8FD8F2  --pink:#FFA9C9
--sand:#FFD166  --lilac:#C3B4FF  --mint:#7FE3B0
--panel:#EDE6FF   /* 精品区整块 */
```

饱和度和奶油底拉得开，又不会刺眼；每个色块都带 `1.5px` 黑描边，
再浅的底也不会糊进卡片背景。

### 落到哪些地方

| 位置 | 之前 | 现在 |
| --- | --- | --- |
| 精品区整块 | 和全部区一样 | 淡紫面板 + 黑描边 + 硬投影，全页面积最大的一处颜色 |
| 分类标签 | 透明底灰字 | 按分类名散列到 5 色，同分类全页同色 |
| 精品徽标 | 黄 | 柠檬绿（把黄让给价格高亮，两个黄挨着会互相抢） |
| 微信 / 邮箱 / Telegram / 社区 | 四个一样的白胶囊 | 绿 / 蓝 / 青 / 紫四层浅底 |
| 自定义链接 | 白胶囊 | 统一沙黄底 `#FFECAE`（v2.9.2 补，见下） |
| 主按钮「查看域名详情」 | 黑底白字 | 紫底白字（黑色留给文字和描边，主按钮再黑就没有行动点了） |
| 选中的筛选项 | 黑底 | 柠檬绿底黑字 |
| 「价格面议」 | 灰 | 紫字 |
| 分区标题的小方块 | 都是黄 | 精品区紫、全部区绿 |

### 分类色号为什么是"算"出来的

```js
export function toneOf(text) {
  let h = 0;
  for (const ch of String(text || '')) h = (h * 31 + ch.codePointAt(0)) % 9973;
  return h % 5;
}
```

要求两条：同一个分类在整页永远是同一个颜色；刷新页面颜色不能变。
所以不能用随机数、也不能按"第几个分类"排 —— 后者在筛选后会重新编号，
"品牌"一会儿粉一会儿蓝。用字符编码求和取模，纯函数、可复现、有单测。

色号写在 `.cat[data-tone="N"]` 上。深色 / 浅色主题没有对应规则，
`data-tone` 在那里是个无副作用的多余属性 —— 这样两个主题的观感完全不变。

### 自定义链接为什么不跟着编号换色

v2.9.2 给头部自定义链接补了一层沙黄底。这里有个反直觉的选择：**所有链接同色**，
而不是像分类标签那样按序号轮换。

区别在数量。分类标签一屏最多五六个，且本来就要区分"品牌 / 生活 / 工具"；
头部链接一排可能十颗（4 条固定联系方式 + 6 条自定义），每条一个颜色会吵成一团，
而且"颜色"在那里没有语义 —— 点哪个都是跳转，区分颜色不会帮用户做任何判断。
同色反而有用：一眼看出"这四个是我的联系方式，后面这些是我挂的链接"。

## 三、验证

- 截图：1400px（neo 桌面）、390px（neo 移动）、1400px 深色与浅色各一张做回归
- 移动端精品区是横向滑动条，加了内边距的紫色面板后不能再往视口外出血
  （`margin:0` 覆盖掉 `-14px`），否则卡片会溢出面板描边
- 断言新增 4 条：色板落在变量里、`toneOf` 可复现且落在 0..4、
  `data-tone` / `data-kind` 出现在该出现的位置、精品区带 `mblock-featured`
- 全套：单测 591、冒烟 32、安全审计 38、打包通过
