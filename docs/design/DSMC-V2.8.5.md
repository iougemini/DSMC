# DSMC v2.8.5 — 米表页的版式与质感

## 一、问题

v2.8.0 把米表做出来了，功能齐但看着素。三个具体的地方：

| 现象 | 原因 |
|---|---|
| 首屏被文字吃掉一半 | 「LOGO + 标题 + 介绍」挤在同一行，标题 24px、介绍 13.5px，抢同一条基线 |
| 页面单调 | 背景是纯色。内容只有几百字，留白很大，纯色显得空 |
| 联系方式右侧空着 | 一行只有微信/邮箱/链接三个胶囊，右边一片空白 |

这一版只调版式，不动数据结构 —— 除了多一个 `nav` 字段。

## 二、头部改两栏

```
┌────────────────────────────────────────────────────────┐
│  [盾] DSMC      域名精选                                │
│                 下面这些域名在售，都可以直接询价。        │
│                                                        │
│  [微信] [邮箱] [联系方式] [全部域名] [GitHub]    [登录] │
└────────────────────────────────────────────────────────┘
```

左边品牌，右边一个 `.mhtext` 包住标题和介绍，上下堆叠。原来是三个 flex 子项
平铺，标题和介绍各自跟 LOGO 抢基线，读起来像一句话。

`.mhtext` 用 `flex:1 1 260px`，窄屏会自动折到品牌下面。

## 三、自定义导航

和联系方式并排，最多 6 项（`MAX_NAV`）。配置在 `config:market` 的 `nav` 里：

```js
nav: [
  { label: '全部域名', url: '/market' },
  { label: 'GitHub', url: 'https://github.com/iougemini/DSMC' }
]
```

为什么是 6：这一行要放「微信 + 邮箱 + 联系链接 + 若干导航 + 登录」。在 1120px
的容器里，每个胶囊约 110px，6 项刚好占满一行；再多窄屏会折成三行，把首屏挤回去。

### URL 的安全边界

只认两种形态：

```
https://example.com/xxx    → 保留，新开窗口
/path                       → 保留，当前窗口
javascript:alert(1)         → 丢弃
data:text/html,<script>     → 丢弃
//evil.example.com          → 丢弃
```

前两个是需求，后三个是安全边界。配置是管理员填的，但 `href` 里的 `javascript:`
就是一条现成的 XSS —— 现在配置只从后台表单来，将来呢？导入、API 写入、迁移脚本，
任何一个入口漏一次校验就够了。校验放在归一化里，所有写入路径自动覆盖。

`//evil.example.com` 单独说一句：它看着像站内路径（以 `/` 开头），其实是协议相对
URL，浏览器会补成 `https://evil.example.com`。正则里用 `\/(?!\/)` 排掉。

### 前端编辑

后台「米表 → 页面设置」里是一列「名称 + 链接 + 删除」，底部一个「+ 添加导航」。

新行从 `<template id="mkNavTpl">` 克隆。用 `<template>` 而不是字符串拼 HTML，
是因为 `document.querySelectorAll` 不会穿透 template 的 content —— 收集表单时
模板行天然被排除，不用额外判断。

保存时只收「名称和链接都填了」的行。半填的行是用户加了一半又放弃，报错太吵。

## 四、背景

两层叠加，都在 `body::before` 上：

```css
radial-gradient(1100px 560px at 50% -4%, var(--glow), transparent 72%)   /* 顶部柔光 */
repeating-linear-gradient(to right,  var(--grid) 0 1px, transparent 1px 72px)
repeating-linear-gradient(to bottom, var(--grid) 0 1px, transparent 1px 72px)
```

- 柔光：深色下是蓝雾（`rgba(116,166,255,.4)`），浅色下是白光
- 网格：72px 一格，不透明度深色 7% / 浅色 7%
- `mask-image` 用径向渐变让它在中段渐隐 —— 不渐隐的话整页都是格子，像草稿纸

第一版把网格设成 4.5%，截图出来几乎看不见（深色背景上 4.5% 的白等于没有）。
调到 7% 才有「质感但不抢内容」的效果。

`body::before` 是 `position:fixed`，所以滚动时光晕不动。这是故意的：
跟着滚的光晕会让人以为加载出了问题。

## 六、遗留

- **导航没有排序**。数组顺序就是显示顺序，后台按行顺序保存。要调整只能删了重加。
  六项以内，暂时够用
- **导航不支持图标**。一列带图标的胶囊看着像工具栏，不像导航 —— 这个取舍是故意的
- **柔光位置写死顶部居中**。换个位置需要改 CSS 变量，没有做成配置项
