# DSMC v2.8.8 变更说明

> 起因：普通用户（访客）视角下有两处「按管理员视角写死」的残留 —— 侧栏留着一个
> 空的分组标题，概览页留着 1/3 宽的空格子。功能没坏，但看着像加载失败。
>
> 这一版只动了两处条件渲染和两段 CSS，没有数据结构变化。

## 一、侧栏：「管理」分组标题跟着它的成员走

```
管理员                          访客（改前）              访客（改后）
┌──────────┐                ┌──────────┐            ┌──────────┐
│ 工作台    │                │ 工作台    │            │ 工作台    │
│  概览     │                │  概览     │            │  概览     │
│  域名     │                │  域名     │            │  域名     │
│  续费     │                │  续费     │            │  续费     │
│ 管理      │  ← 标题        │ 管理      │ ← 只剩标题  │ 项目      │
│  账户     │                │ 项目      │            │  关于     │
│  米表     │                │  关于     │            │          │
│  通知     │                └──────────┘            └──────────┘
│  设置     │
│ 项目      │
│  关于     │
└──────────┘
```

`shell.js` 里那四项本来就写成 `isAdmin ? navItem(...) : ''`，唯独分组标题是
无条件输出的。访客进来看到「管理」下面空着，第一反应是导航没加载完。

**改法**：标题与成员用同一个条件。

```js
// 改前
'<div class="nav-label">管理</div>' +
(isAdmin ? navItem('accounts', ...) : '') + …

// 改后
(isAdmin ? '<div class="nav-label">管理</div>' : '') +
(isAdmin ? navItem('accounts', ...) : '') + …
```

「工作台」「项目」两个标题不动 —— 它们下面的成员对所有身份都渲染。

## 二、概览页：访客的「到期分布」占满整行

概览是三列网格（`.grid{grid-template-columns:repeat(3,minmax(0,1fr))}`），
卡片靠 `span2` / `span3` 占位：

| 行 | 管理员 | 访客（改前） | 访客（改后） |
| --- | --- | --- | --- |
| 1 | 待办 hero(2) + 状态分布(1) | 同左 | 同左 |
| 2 | 到期分布(2) + **账户**(1) | 到期分布(2) + **空格** | 到期分布(**3**) |
| 3 | 精选域名(3) | 同左 | 同左 |
| 4 | 需要关注(3) | 同左 | 同左 |

账户卡只在管理员下渲染（访客看不到账户页，挂个「点了没反应」的入口没意义），
于是第二行右边空出三分之一。

**改法**：让卡片自己判断该占几列。

```js
'<section class="card ' + (isAdmin ? 'span2' : 'span3') + '">'
```

`span3` 在三个断点下都已经有正确行为（≤某宽度降成 `span 2`，再窄降成 `span 1`），
所以不用额外写媒体查询。

### 柱子跟着放宽

跨满整行后，13 根 `max-width:26px` 的柱子散在一千多像素里像掉了几颗钉子：

```css
.span3 .bar{max-width:44px}
```

选 `.span3 .bar` 而不是给到期分布单独加类名，是因为另外两张 `span3` 卡片
（精选域名、需要关注）里根本没有 `.bar`，不会误伤。

### 手机上的周标签

这一条是顺手修的，不在原需求里：13 个周标签在 390px 下每格只有 25px，
而「11/15」就要 24px，相邻两个会咬在一起。

```css
@media (max-width:520px){
  .bar-col:nth-child(even) .bar-label{visibility:hidden}
}
```

隔一个显示一个 —— 柱子一根不少，时间轴仍然读得出来（7 个标签覆盖 13 周）。
用 `visibility` 而不是 `display:none`，因为后者会让标签行高度塌陷，
柱子会往下跳一格。
